## 结果记录要求

每次执行注明日期、Git 分支或代码版本、工具版本、数据环境、测试命令/步骤、实际结果和未覆盖内容。外部动作分别保存请求结果和设备实际状态；不能把 HTTP 200、Mock 成功或构建通过填写为真机实车通过。

完整上线验收需要消除真实资源阻塞。模拟交付可以验收本地业务状态与权限，但不将本矩阵中的外部依赖项勾为完成。
