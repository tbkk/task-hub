# 本地模拟交付

## 验证入口

在项目根目录执行 `scripts/verify-delivery.sh`。脚本依次运行后端 Maven 测试、管理端测试与构建、小程序测试、类型检查及 H5/微信构建。

本地服务使用 `deploy.sh` 启动，模拟车辆、模拟身份和站内消息只允许 local/test profile。模拟控制的 `ACCEPTED` 仅表示请求受理，车辆状态仍需通过模拟事件推进。

## 主流程

申请人提交订单后，由仓库受理、组批、分配车辆与格口并确认装货；调度人员派发并核对请求，模拟车辆推进到 `ATSTOP`；每位接收人扫码后只能看到自己的订单，开门请求和取货确认分别记录；全部订单完成、门状态新鲜且无工单阻断时，调度人员才能继续出发。

真实微信、九识 API/MQTT、测试车辆和真机不在本地模拟验收范围内。
