# 工单独立生命周期实施计划

> 使用 executing-plans 与TDD，执行既有S17。

**目标：** 真实持久化工单创建、受理、说明、关闭与范围查询，不改变订单/车辆事实。
**架构：** V10 ticket/active_order_ticket/ticket_note；TicketService处理幂等、版本、事务、任务锁；TicketController薄适配；SqlTicketBlocker供控制事务共用。
**技术栈：** Spring Boot、JdbcTemplate、MySQL。

## 约束
- 不提交推送，中文文档；工人仅本人提交，仓库本角色仓库范围。

- 创建先锁当前车辆/任务，再锁订单；控制须共用相同锁。关闭只改变工单。
- 各写操作expectedVersion和Idempotency-Key，审计事件同事务；未知结果保留原key。
