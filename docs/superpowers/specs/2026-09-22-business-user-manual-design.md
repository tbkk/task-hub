# 业务人员操作手册设计

日期：2026-09-22

状态：用户已确认设计，正式手册已写入 [用户操作手册](../../用户操作手册.md)。

## 目标与读者

为本地演示环境的业务人员提供中文操作手册。读者包括管理平台管理员、工人和仓库人员；不面向开发、部署或数据库运维人员。

## 交付形式

创建 `docs/用户操作手册.md`，在 `docs/README.md` 增加入口。手册使用按角色组织的短步骤，每个角色只展示其实际可访问且已实现的功能。

## 内容结构

1. 使用范围：说明本地管理平台和小程序 H5 入口，列明演示环境边界。
2. 开始前准备：管理员先维护仓库、员工所属仓库与业务角色；员工完成手机号登录。
3. 管理员操作：仓库、停靠点、车辆、格口、营业规则、装货点和人员授权。强调工人须配置所属仓库才能申请。
4. 工人操作：手机号登录、提交申请、选择目的地与预约时段、查看订单、申请取消。
5. 仓库人员操作：审批订单、处理取消申请、创建与编辑配送批次。
6. 常见问题：未配置所属仓库、没有目的地或时段、没有业务入口、订单被他人更新和提交结果待确认。
7. 当前未开放功能：装货、调度、取货、工单、消息、概览、报表、真实微信/短信和实车操作。

## 表述与安全边界

- 不记录真实数据库密码、模拟验证码、会话令牌或管理员密码；手册用“联系本地环境管理员获取演示凭据”表述。
- 不将 H5 操作描述为微信真机、真实短信、真实车辆或正式生产验收。
- 对取消申请明确“提交取消申请不等于订单已取消”，由仓库人员处理。
- 对批次明确仅能合并同仓、同目的地、同时段且已受理的订单。

## 验收方式

- 手册中的入口、导航名称和页面功能与当前管理端、小程序 H5 路由一致。
- 不包含未实现操作或敏感凭据。
- Markdown 格式与相对链接检查通过，文档索引可访问。
