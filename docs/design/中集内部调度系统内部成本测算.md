# 中集内部调度系统内部成本测算

日期：2026年9月18日  
用途：仅供开发方内部评估，不作为客户报价附件。

本文件与《中集内部调度系统功能范围与报价.md》配套，记录谈判区间及自有团队开发交付的成本测算方法。项目由开发方自行开发、测试、联调及维护。金额均为人民币，实际成本需根据团队投入填写。

## 一、谈判区间

| 项目 | 对客建议价 | 内部参考成交区间 |
|---|---:|---:|
| 标准版开发 | 128,000～158,000元 | 128,000～158,000元；实际底价待成本核算 |
| 标准年度维护 | 24,000元/年 | 20,000～24,000元/年 |

开发报价按本次要求统一为128,000～158,000元，维护报价不变；上述区间不是市场成交数据或已验证的成本底价。现有功能范围不变，仍由自有团队交付。签约前需核算实际投入及可复用代码，任何缩减范围均需另行确认。

## 二、自有团队开发成本测算

目前尚未确定团队人数、投入人日及内部综合人日成本，因此不预设开发总成本或利润率。客户报价已按24个模块分别列出区间，合计128,000～158,000元；这是既定总预算内的销售报价分配，不等于内部实际成本或各模块独立采购成本。共用建设和交付工作只计一次，详见报价文档第3.2节。

新版按110～140人日作为初步工作量预算，用于排期和成本试算，后续用实际页面、流程及联调范围细化。该范围是项目估算，尚非团队承诺。以下只计算一次各项工作，专项接口测试与整体验收测试分开计数。

| 工作内容 | 初步人日 |
|---|---:|
| 需求、原型与UI设计 | 12～16 |
| 工人小程序前端 | 18～22 |
| PC仓库与管理员前端 | 16～20 |
| 业务后端、人工合单、工单、权限及留存 | 24～30 |
| 九识API/MQTT集成及接口专项联调 | 18～24 |
| 整体回归、验收、部署、文档、培训及项目协调 | 22～28 |
| **合计** | **110～140** |

若仍按原110～140人日估算，128,000～158,000元开发报价对应约914～1,436元/人日的综合销售收入，尚未扣除成本，不能据此认定项目可盈利。须按实际复用方案评估投入，并据此核算成本与利润。原10～14周周期以2～3名开发协作、设计测试阶段性参与为前提；单人投入约22～28个工作周，另需考虑客户和厂商等待时间。

新增范围以同仓库、同停靠点、同预约时段人工合单、PC仓库端、文字异常工单、普通小程序首页跳转为基准。不包含多站智能调度、仓库手机工作台、九识APP完整复制或免登录车辆直达。

| 成本项 | 测算方式 |
|---|---|
| 需求、原型与设计 | 实际投入人日 × 对应内部综合人日成本 |
| 小程序、管理后台及后端开发 | 各人员实际投入人日 × 对应内部综合人日成本 |
| API/MQTT对接、测试与实车联调 | 实际投入人日 × 对应内部综合人日成本 |
| 项目沟通、部署、文档与培训 | 实际投入人日 × 对应内部综合人日成本，避免与以上项目重复计入 |
| 免费保修与返工预留 | 预计支持人日 × 对应内部综合人日成本 |
| 开发环境、工具及未向客户另收的差旅 | 按项目实际承担费用计入 |

内部综合人日成本按团队实际薪酬及相关用工成本计算；个人自行开发也应计入自己的时间成本。不同角色可采用不同单价，开发周期不等于总投入人日。

项目贡献 = 实际未税开发收入 − 项目人力成本 − 保修与返工预留 − 项目直接费用。

项目贡献尚需扣除未分摊的获客和公司固定开支等，不能直接视为净利润；已计入综合人日成本的费用不再重复扣除。

## 三、自有团队维护成本

维护报价也应预留实际支持工时：24,000元/年、每月最多10小时，对应全年最多120小时，服务收入约200元/小时；尚需覆盖监控巡检、沟通、管理和故障处理成本。不能同时承诺无限修改或24小时值守。工单模块的程序故障属于维护，仓库业务工单的日常处理不属于开发方维护服务。

维护成本按实际支持工时及内部小时成本核算。厂商联调等待造成的排期占用、突发故障排查及免费保修投入均需预留，不能只计算编码时间。
