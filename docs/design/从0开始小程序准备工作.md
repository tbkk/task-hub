一、必须开通的账号
1. 微信小程序企业账号
在微信公众平台注册，账号类型选择“小程序”，主体选择公司。
准备：
- 未注册过公众平台账号的企业邮箱
- 营业执照
- 企业名称、统一社会信用代码
- 法定代表人信息
- 小程序管理员的实名微信、身份证、手机号
- 企业对公账户或法人验证材料
- 小程序名称备选 2～3 个
- 小程序头像、简介
- 服务类目
建议使用公司长期在职人员作为管理员，不要完全绑定外包公司或短期员工。注册完成后会获得：
- AppID
- AppSecret
- 开发者、体验人员管理权限
你们需要获取员工微信绑定手机号，建议完成企业主体认证；手机号快速验证能力可能涉及调用额度和费用，需要在公众平台的“付费管理”中准备相应预算。

2. 企业云服务账号
阿里云以公司主体注册并实名认证。建议不要使用开发人员的个人云账号。
需要设置：
- 1名公司主账号管理员
- 开发人员使用子账号
- 财务联系人
- 安全告警联系人
- 账户余额或企业付款方式
- 登录保护和 MFA

二、服务器及网络资源
几百名员工、十几名管理员，如果请求频率不高，初期不用购买很高配置。
建议准备：
资源	初期建议
云服务器	2核4GB 起步
数据库	云数据库 MySQL，或独立数据库实例
系统盘	50～100GB
文件存储	有附件时开通对象存储
域名	公司持有的独立域名或子域名
HTTPS	SSL证书，必须配置
备份	数据库自动备份，至少保留7～30天
日志	API调用日志、管理员操作日志、错误日志
监控	CPU、内存、磁盘、接口错误及服务器宕机告警

例如购买主域名 example.com 后，可规划：
- api.example.com：小程序后端接口
- admin.example.com：管理员网页后台
- file.example.com：附件访问，可选
小程序只能请求后台配置过的服务器域名，正式环境通常要求 HTTPS，不能直接把服务器 IP 作为正式接口地址。小程序网络域名规则

三、域名与备案
需要区分两类备案：
- 域名/网站 ICP 备案：服务器位于中国大陆时，通常需要通过云服务商办理。
- 小程序备案：通过微信公众平台提交。
小程序备案一般需要：
- 营业执照
- 企业注册地址、通信地址
- 主体负责人信息
- 小程序负责人信息
- 身份证、手机号、邮箱
- 授权书，负责人不是法人时可能需要
- 小程序名称、服务内容和服务类目
- 前置审批材料，特殊行业才需要
- 短信核验及人脸/现场核验
境内提供服务的小程序需要完成备案后再开展业务，审核材料齐全时，主管部门规定的备案处理期限可以达到20个工作日，因此要提前安排。工信部备案规定

四、隐私和合规材料
因为会收集手机号、员工身份和请求处理记录，至少准备：
- 《用户隐私保护指引》
- 《用户服务协议》或内部使用说明
- 个人信息收集清单
- 数据保存期限
- 离职人员数据处理规则
- 客服或隐私联系人
- 信息安全事件处理联系人
隐私指引中要明确说明手机号用于“员工身份验证和内部访问控制”，不要笼统写成“提升用户体验”。

推荐办理顺序
1. 确定小程序名称、管理员和业务负责人。
2. 注册企业小程序账号并完成认证。
3. 注册企业云账号。
4. 购买公司域名并完成实名认证。
5. 选择中国大陆服务器，开始域名 ICP 备案。
6. 准备隐私政策及内部使用规则。
7. 开发、测试。
8. 完成小程序备案、平台审核并上线。
