# 中集内部调度系统｜小程序与管理平台功能划分

> 当前执行范围（2026-09-19）：现阶段只做标准版功能，其他不做。额外能力仅留档，不作为待执行任务。已要求的日常业务迁移小程序继续保留。

版本：V2.2（本期范围收敛，支持一人多角色）；日期：2026-09-19。

最新划分原则由用户明确：**日常业务操作全部放小程序，非日常业务的管理与支撑功能放管理平台。** 本版替代此前「仓库轻工作台＋PC 调度后台」建议。P01–P40 为原功能编号，用于追溯，不代表全部仍是小程序页面。

## 1. 端定位

- **小程序是日常业务工作入口**：工人、仓库、调度在手机上完成申请、审批、合单、装货、派车、车辆控制、取货、异常处理及业务查询，不需要切换到电脑才能完成业务闭环。
- **管理平台是系统管理与支撑入口**：人员权限、基础资料、基础业务规则、既有第三方接入、运行维护、系统审计及管理报表。
- 业务复杂或需要多选，不构成移到管理平台的理由；小程序使用筛选、多选、分步确认和底部操作栏完成。
- 管理平台不重复建设审批、合单、派车、取消车辆任务或关闭业务工单的操作入口。管理员若需参与日常业务，使用小程序中的已授权业务工作区。

### 一人多角色规则

- 一个人对应一个内部账号，可同时拥有工人、仓库、调度、管理员等多个角色。
- 管理平台使用角色多选控件，逐角色配置数据范围；同一员工在列表中一行显示多个角色标签。
- 小程序在首页顶部／个人中心切换已授权工作区，无需退出登录；切换不改变账号本身的角色分配。
- 平台菜单按已授权能力展示，操作与数据范围必须来自匹配的角色授权，不能用全厂查看权扩大全部角色的操作范围。
- 移除一个角色保留其他角色与业务历史；整体停用账号则全部角色失效。权限变化后及时刷新页面和操作校验。
- 记录同一真实操作人和当次角色／授权依据；消息按账号去重。一人可跨多个已授权岗位办理业务，不默认新增岗位互斥要求。

## 3. 容易混淆的边界

- **审批属于日常业务**：仓库受理申请和处理取消都在小程序，不因为具有审核性质就放管理平台。
- **本次订单分格口属于业务**：在小程序完成；车辆有几个格口、格口如何绑定硬件属于基础配置，在管理平台完成。
- **待办数量和当天进度属于业务看板**：在小程序展示并下钻；跨周期汇总、趋势报表和批量导出放管理平台。本次不默认增加手机报表导出。
- **业务履历属于业务查询**：取货时间、派发结果、工单结果在小程序可查；权限变更和系统故障日志在管理平台审计。
- **车辆异常属于业务**：任务结果待核对、门状态异常由小程序核对处理；接口接入、消息连接、备份及服务监控由管理平台维护。

## 4. 小程序导航与业务闭环

### 工人工作区

「申请／订单／消息／我的」：申请、查单、取消申请、扫码取货、继续出发、反馈与结果查询。

### 仓库工作区

「工作台／配送批次／消息／我的」：申请审批、取消处理、合单、格口分配、装货、异常工单全流程。工作台提供待办数量与业务筛选。

### 调度工作区

「调度台／车辆／消息／我的」：选车派单、任务取消、车辆控制、最新位置、执行记录与业务核对。

### 业务概览工作区

拥有全厂查看权限的人员可使用「概览／业务记录／消息／我的」查看全厂日常业务。该工作区不包含人员、权限或系统配置；具体业务操作仍须授予相应仓库／调度权限。

### 完整业务流程

工人提交 → 仓库受理 → 合单／单独成批 → 选车及格口分配 → 装货确认 → 调度派车 → 配送 → 工人扫码取货 → 符合条件后继续出发。以上全部在小程序完成。

异常流程：工人反馈 → 仓库受理 → 现场核对并填写说明 → 仓库填写结果关闭 → 工人查看结果，同样全部在小程序完成。

## 5. 管理平台页面范围

| 编号 | 页面组 | 主要内容 |
|---|---|---|
| M01 | 平台登录与账户 | 平台身份验证、登录状态、退出 |
| M02 | 人员与权限 | 员工查询、准入、验证状态、启停用、仓库归属、角色与数据范围；保存变更留痕，不以资料修改代替手机号验证 |
| M03 | 基础资料 | 仓库、停靠点、车辆、硬件格口定义及同步；停用显示影响，历史记录保留 |
| M04 | 规则配置 | 营业时间、预约容量、文字限制、超时／状态有效期；校验取值和单位 |
| M06 | 既有第三方接入 | 九识 API/MQTT、普通小程序入口及登录验证码配置；凭证安全维护 |
| M07 | 管理报表 | 按日期、仓库筛选统计，下钻只读明细，导出；记录操作者、条件和时间 |
| M08 | 审计与运行维护 | 角色／配置变更、系统日志、接口及连接监控、业务留存；基础运维使用既有部署工具与文档，不要求独立自建运维平台 |

管理平台读取业务数据供统计审计，不提供日常业务处理按钮。非业务支撑项的设置发布到服务端后，小程序读取最新有效配置；涉及正在处理的订单或任务时再次校验并说明变化。

## 6. 本期范围与原型要求

本次用户同意将自动派车、实时地图、轨迹回放、远程关门、返航、独立到达预测及倒计时、业务短信、微信订阅、免登录、车辆直达和完整 APP 复刻移入《中集待确认扩展功能清单》。相关后台配置一并移出，两端不生成本期入口或占位菜单。

小程序保留 P01–P29、P33、P34、P40，共 32 项本期业务编号；P35、P36 保留为管理端对应编号。管理平台按当前说明生成 15 项主要画板，原编号保留追溯。

已要求的仓库、调度和日常业务查询迁移小程序继续保留；它是相对于原 PC 标准版的端划分变更，不代表所有扩展能力同时获批。原需求文档与报价保留为历史基线，本次不修改金额或承诺合同已变更。

独立导出任务中心、系统健康首页、告警处理台和可视化备份管理不作为本期必交付界面。基础导出、监控、错误日志、备份与恢复验证仍保留，通过现有工具和文档交付。

所有端共用服务端权限和状态校验；不能用扫码、管理员身份或切换工作区绕过权限，不能把接口受理当作车辆实际执行成功。
